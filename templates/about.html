About

Hello. This is a project I have been working on for little while. This is a web portal for finding users and bad actors that should be moderated. It uses a number of Roblox's APIs to collect data. After submiting a UserID or GroupID remember to update the database (DB) before visting the Stats or Sentiment Analysis pages. This is mostly meant as a proof of concept. The stats page literally just dumps the database onto the page. - It also shows some basic stats. The Sentiment Analysis page runs Sentiment Analysis on the user description with a Sentiment Analysis model I trained awhile back."

Useage

The main useage is collecting users associated with a bad actor. This is done either by providing a GroupID or thier UserID. Providing the GroupID collects all the users in that group. Providing the UserID collects all the connections of that user.

The UserID is the number in the url: https://www.roblox.com/users/1320922/profile/

The GroupID is the number in the url: https://www.roblox.com/communities/2658221/Lumber-Tycoon-2-Fans#!/about

Updating the database can take a long time. This is not becuase my code is bad, well some of it is. This is mainly becuase the API I use to collect the data for each user will rate limit me if I attempt to process 5 users per second. This is the same reason why getting to URLs of Roblox profile pictures also takes a long time.

Limitations

This tool was not disinged with multiple users using the tool at the same time. So at this point in time it is reccomneded that you do not use this tool with multiple users simultaneously.
